## 一句话核心

> **资产决定作品上限，提示词只能决定下限。**
> 场景资产的正确姿势：**先定空间关系（拓扑），再分室外/室内生成，最后锁色卡** —— 顺序错了，后面每张图"各画各的"必然出错。

## 演示案例（理解上下文）

一家三口在雪林里拼命下山逃亡 → 到山脚抬头，发现坡顶有一栋农舍。

## 场景资产构建六步流程

| 步骤 | 产物 | 要点 |
|---|---|---|
| ① 场景清单 | 场景清单 | **按剧本事件节点列出**（不是按地点随手列） |
| ② 室外拓扑图 | 拓扑关系图（**第一张图，不是任何具体场景**） | 雪林在哪 / 农舍在哪 / 两者间隔多远 / 坡从哪个方向斜 / 人物整条动线怎么走 |
| ③ 室外场景 | 室外分节点出图（本案例 3 张） | 雪林下坡、林缘坡角、**从坡角反打过去的农舍** |
| ④ 室内户型平面图 | 户型平面图（**室内一致性最关键一张**） | 不直接画房间图，先做平面图 |
| ⑤ 室内场景 | 各关键节点室内图 + **宫格图** | 保证"每一张都是同一个房间" |
| ⑥ 色卡 | 室内色卡 + 室外色卡 | 为视频环节光影/色调不漂移保驾护航 |

## 关键机制详解

### 为什么第一张图必须是"室外拓扑图"（本视频最强调的点）
- 如果没有把**空间关系**（位置、距离、坡度方向、人物动线）先定下来，后面每一张图各画各的跑出来，**必然出错**。
- 拓扑图确认后，场景分成**室外 / 室内**分开生成，各走各的管线。

### 室内一致性：户型平面图 → 宫格图（两级保障）
1. **户型平面图**（空间关系层）：
   - 案例：爸爸在客厅、门厅、餐厅、后边楼梯间来回跑好几次。
   - 有了平面图才知道：每次从哪个门进、哪个方向走、下一个场景该出现在哪。
   - **没有这张图，空间关系无法保证，人物必然"在自己家里迷路"。**
2. **宫格图**（单房间一致层，解决"每张室内图怎么保证是同一个房间"）：
   - 以当前这张室内图为基准 → 把该房间的空间关系**在内部推演一遍** → 一次性生成这个房间的各个角度：**正打 / 反打 / 左右侧 / 后续可能需要的一些特写机位**。

### 色卡（最后一步，容易被忽视）
- 分别针对**室内**和**室外**各出一套。
- 用途：为后面**最重要的视频环节**——光影和色调不漂移——保驾护航。
- 另外：**人物匹配的音色**（voice asset）要一并准备好，才算完整资产包。

## 与上期（角色资产）合并后的完整资产包顺序
1. 建账本（上期）→ 2. 剧本拆解 + 情绪曲线（上期）→ 3. 视觉锁定（上期）→
4. **人物资产**：血缘继承 + 垫图 + 状态图 + 三视图（上期）→
5. **道具资产**：只留重复出现道具（上期）→
6. **场景资产**：场景清单 → 室外拓扑图 → 室外节点图 → 户型平面图 → 室内节点图（宫格图）→ 色卡（本期）→
7. 人物匹配**音色**（本期提到）

## 评论区技术点（来自该视频评论区，关于参考图与算力）
- Seedance 系列所有参考图分配给一段视频的算力是**有限的，按时长分配**：
  - 过大的参考图（4K）或**过多的参考图**都会让分配给视频的算力变少。
  - 事实上**一张反打图就足够了** —— 资产不在多，够用且精。
