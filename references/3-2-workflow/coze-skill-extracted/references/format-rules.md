# 格式规则

## 对白格式规则

### 三种对白类型

| 类型 | 格式 | 示例 |
|------|------|------|
| 说出的台词 | [角色名]开口说道："[内容]" | 韩非开口说道："各位老师好。" |
| 内心独白 | [角色名]心中涌起："[内容]" | 张三心中涌起："我不能输。" |
| 旁白/画外音 | 画外音响起："[内容]" | 画外音响起："那是十年前的夏天。" |

### 对白书写位置

- 对白写在切镜末尾的句号之后
- 同一角色连续说话时，每个切镜末尾均可写对白
- 不同角色对话时，切换切镜并写各自对白

### 对白字数与时长

- 基准秒 = ceil(汉字字数 ÷ 4)
- 英文/数字按半个汉字计算
- 标点符号不计入

## 音效格式规则

### 基本格式

```
[音效：具体描述]
```

### 书写位置

- 音效写在切镜末尾
- 顺序：对白之后 → 时长标注之前
- 无对白时：直接接音效

### 格式示例

```
【切镜】近景胸像，固定镜头，张三猛然回头。[音效：门被撞开的巨响][约2s]
【切镜】大全景，固定镜头，空旷的走廊。[约3s]
```

### 音效描述原则

- 使用具体可感的拟声词
- 避免抽象描述
- 同一场景音效可省略（首镜已建立则后续可省略）

### 禁止项

- 禁止在画面正文中描述声音（用"传来"、"响起"等）
- 禁止用音效代替画面描述
- 禁止写背景音乐（见第三阶段格式要求）

## 时长计算规则

### 计算公式

```
最终时长 = 基准秒 + 动作秒，向上取整
最低时长：2秒（无特写要求时）
最低时长：4秒（情绪特写）
```

### 台词基准秒计算

1. 统计台词汉字总字数
2. 基准秒 = ceil(字数 ÷ 4)
3. 无台词时基准秒 = 0

### 动作秒叠加规则

| 动作类型 | 示例 | 动作秒 |
|----------|------|--------|
| 简单动作 | 站立、转头、表情变化、静止凝视、挥手、点头 | 2秒 |
| 中等动作 | 行走、单次出招、跌倒、缓慢移动、开门、坐下 | 3~4秒 |
| 复杂动作 | 多人缠斗、大范围位移、技能释放、连续攻击、爆炸 | 5~8秒 |
| 氛围空镜 | 无人物动作，纯景别渲染 | 固定3~4秒，无对白加成 |

### 向上取整规则

- 计算结果非整数时向上取整
- 示例：基准秒2 + 动作秒3 = 5秒（直接取整）
- 示例：基准秒2 + 动作秒2 = 4秒（直接取整）
- 示例：基准秒1 + 动作秒2 = 3秒（向上取整）

### 情绪特写最低时长

- 情绪特写（表达悲伤/愤怒/喜悦/震惊等强烈情感）
- 最低4秒，确保情绪有足够时间传达

## 批次规则

### 批次定义

- 单批次最长15秒
- 即将超过15秒时，当前镜号开启新批次并重置计时

### 批次标记格式

| 位置 | 格式 |
|------|------|
| 批次第一个镜号 | 批次N（共X秒） |
| 同批次后续镜号 | 批次N |

### 分镜表"生成批次"列

```
镜号1：批次1（共14秒）
镜号2：批次1
镜号3：批次1
镜号4：批次2（共12秒）
镜号5：批次2
```

### 批次合并策略

- 相差1~2秒的批次可合并以尽量填满15秒
- 合并后批次时长可超过15秒但不超过18秒（建议值）

### 批次衔接提示（输出给用户）

```
衔接提示：生成视频时，每完成一个批次，请截取该批次视频最后一帧，
作为下一批次的首帧参考图上传至 Seedance，可有效避免批次间画面断层。
```

## 提示词格式补充规则

### 资产标注句

**格式**：
```
@是[角色名]，@是[场景名]，[声音资产（如有）]，[STYLE_TOKEN完整描述词]，在[场景名]，[光影基调]。
```

**规则**：
- STYLE_TOKEN 必须展开为完整描述词
- 只写本镜号实际出现的角色和场景
- 严禁写入 @参考图
- 同一角色只声明一次

### 声音资产触发规则

| 触发词 | 声音资产 |
|--------|----------|
| "说道" | @是[角色名]的声音 |
| "心中涌起" | @是[角色名]的声音 |
| 旁白/画外音 | @是旁白的声音 |

### 切镜格式

**基本格式**：
```
【切镜】[景别]，[非默认角度]，[运镜词]，[角色名][非正面朝向][动作]，[微表情]。[对白][音效][约Xs]
```

**过肩镜头格式**：
```
【切镜】[景别]，过肩镜头，[焦点层次]，[运镜词]，[角色名][动作]。[音效][约Xs]
```

### 结束行（强制）

代码块最后一行必须为：
```
只添加音效和台词，禁止添加背景音乐，禁止出现字幕。
```

## 分镜表格式规范

### 表格列定义

| 列名 | 说明 | 格式示例 |
|------|------|----------|
| 镜号 | 序号 | 1, 2, 3... |
| 时长(秒) | 该镜号总时长 | 5 |
| 生成批次 | 批次编号 | 批次1（共12秒）/ 批次1 |
| 景别 | 从景别词库选择 | 近景胸像 |
| 构图+运镜 | 角度+运镜组合 | 斜前方45度，缓缓推近镜头 |
| 画面内容 | 详细画面描述 | 韩非站在讲台上，神情从容 |
| 出场人物 | 该镜号出场角色 | 韩非 |
| 场景(+光影基调) | 场景+光影 | 答辩教室，白炽灯冷光 |
| 对白/独白/旁白 | 台词内容 | "各位老师好，我是韩非。" |

### 分镜表输出格式

```markdown
| 镜号 | 时长(秒) | 生成批次 | 景别 | 构图+运镜 | 画面内容 | 出场人物 | 场景(+光影基调) | 对白/独白/旁白 |
|------|----------|----------|------|-----------|----------|----------|----------------|----------------|
| 1 | 5 | 批次1（共14秒） | 全景 | 固定镜头 | 韩非面朝评委席站于讲台，双手持翻页笔，神情从容 | 韩非 | 答辩教室，白炽灯冷光打顶，暖色投影映衬 | "各位老师好，我是韩非。" |
```

## 常见格式错误示例

### 错误1：切镜写在同一行
```
❌ 【切镜】全景，【切镜】近景（错误）
✅ 【切镜】全景，...
✅ 【切镜】近景，...
```

### 错误2：对白格式错误
```
❌ 张三说：各位老师好
✅ 张三开口说道："各位老师好。"
```

### 错误3：背对镜头描述表情
```
❌ 背对镜头，张三面露悲伤
✅ 背对镜头，张三肩膀微微颤抖
```

### 错误4：特写局部重复
```
❌ 特写，手部特写
✅ 手部特写
```

### 错误5：时长标注位置错误
```
❌ 【切镜】近景，约3s张三开口道...
✅ 【切镜】近景，张三开口道..."[约3s]
```
