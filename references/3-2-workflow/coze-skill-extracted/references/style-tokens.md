## 自定义风格八步推导法

当用户选择⑨或说出非预设风格时，必须严格按以下八步执行。

### 第一步：识别风格来源类别

从以下类别中确定主要来源方向：

| 类别 | 示例 |
|------|------|
| 艺术家/画家风 | 梵高、莫奈、浮世绘、国画大家 |
| 电影导演风 | 王家卫、诺兰、李安、张艺谋 |
| 动画师/工作室风 | 宫崎骏、新海诚、皮克斯、梦工厂 |
| 摄影师风 | 荒木经惟、 Annie Leibovitz |
| 游戏IP风 | 原神、王者荣耀、最终幻想 |
| 时代美学风 | 赛博朋克、蒸汽朋克、废土美学 |
| 用户自创描述 | 用户直接描述的视觉偏好 |

### 第二步：提取静态视觉特征

分析以下三个维度：

1. **色彩体系**
   - 主色调：暖/冷/中性
   - 饱和度：高/中/低
   - 对比度：高/中/低
   - 特殊色调倾向：霓虹/莫兰迪/赛博绿/复古黄

2. **光影质感**
   - 光源类型：自然光/人工光/混合光
   - 光影风格：硬调/软调/戏剧性/高对比
   - 特殊光效：霓虹/逆光/暗角/光晕

3. **画面质地**
   - 胶片/数码/手绘/CG/水墨/油画
   - 颗粒感/柔焦/锐利/模糊
   - 画幅比例/特殊构图

### 第三步：提取动态运镜特征

1. **镜头运动偏好**
   - 持稳方式：手持/稳定器/滑轨/固定
   - 运动速度：快/慢/匀速/变速
   - 运动幅度：小幅/大幅/航拍

2. **运镜类型偏好**
   - 推进类：推近/拉远/跟随
   - 旋转类：环绕/甩镜/摇镜
   - 特殊类：FPV/POV/升格/降格

### 第四步：提取时间节奏特征

1. **帧率感**
   - 标准帧率：24fps/30fps/60fps
   - 特殊帧率：升格慢动作/降格快动作

2. **运动曲线**
   - 缓入缓出/匀速/弹性
   - 物理模拟/动画曲线

3. **节奏偏好**
   - 快切/长镜头/单镜凝视
   - 剪辑节奏：紧凑/舒缓

### 第五步：合并三层为完整描述词

**结构**：`[风格总称]` + `[静态视觉特征]` + `[动态运镜特征]` + `[时间节奏特征]`

**字数要求**：40~80字

**示例**：

王家卫风格推导结果：
```
王家卫电影风格，霓虹色调冷暖对撞，浅景深虚化背景，抽帧慢快门拖影质感，手持轻微晃动，24fps电影帧率，升格慢动作与降格快切交替，延长单镜头的凝视感
```

诺兰风格推导结果：
```
诺兰电影风格，IMAX大画幅质感，低饱和冷峻调色，自然光戏剧性对比，稳定器平滑运镜为主，24fps电影帧率，长镜头推进式运动，匀速几何感运动曲线
```

### 第六步：合理性自检

检查以下三点：

1. **与剧本题材协调性**
   - 风格是否与剧本类型匹配（如：喜剧不适合太暗的色调）
   - 风格是否与时代背景匹配（如：古装剧不适合赛博朋克）

2. **描述词可执行性**
   - 是否为具体可实现的视觉特征
   - Seedance 是否能理解并生成

3. **三层特征齐全性**
   - 静态视觉层：色彩/光影/质地
   - 动态运镜层：运动方式/速度/类型
   - 时间节奏层：帧率/曲线/节奏

### 第七步：输出推导结果给用户确认

**输出格式**：

```
推导完成，以下是[用户输入风格名]的 STYLE_TOKEN：

【静态视觉层】[静态视觉描述]
【动态运镜层】[运镜特征描述]
【时间节奏层】[节奏特征描述]

合并后的完整 STYLE_TOKEN（将用于所有提示词）：
[完整描述词，40~80字]

与剧本题材协调性检查：[说明是否协调，若冲突给出建议]

如方向无误请回复「确认」，我将锁定此风格继续执行。如需调整请直接告诉我具体方向。
```

### 第八步：用户确认后锁定

- 确认后 STYLE_TOKEN 全程不可更改
- 所有后续分镜和提示词均使用锁定后的 TOKEN
