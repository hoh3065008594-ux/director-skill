# 运镜词库

## 运镜分类总览

| 类别 | 说明 |
|------|------|
| 固定类 | 镜头静止不动 |
| 平移类 | 镜头在空间中直线移动 |
| 旋转类 | 镜头围绕中心点旋转 |
| 变焦类 | 镜头焦距变化改变视角 |
| 环绕类 | 镜头围绕主体做弧线运动 |
| 航拍类 | 空中/特殊角度运镜 |
| 特殊类 | POV/升格降格等特殊效果 |

---

## 固定类

| 运镜词 | 说明 |
|--------|------|
| 固定镜头 | 镜头完全静止 |
| 手持镜头 | 模拟手持的轻微晃动 |

---

## 平移类

| 运镜词 | 说明 |
|--------|------|
| 向前推进 | 镜头直向前移动，推近主体 |
| 向后拉远 | 镜头直向后移动，拉远主体 |
| 向左横移 | 镜头水平向左移动（俗称左摇） |
| 向右横移 | 镜头水平向右移动（俗称右摇） |
| 垂直上升 | 镜头垂直向上移动 |
| 垂直下降 | 镜头垂直向下移动 |
| 跟随主体移动 | 镜头跟随人物/物体移动 |

---

## 旋转类

| 运镜词 | 说明 |
|--------|------|
| 向左水平旋转 | 镜头原地水平向左旋转 |
| 向右水平旋转 | 镜头原地水平向右旋转 |
| 快速甩镜 | 快速的方向切换，制造转场或突发感 |
| 向上仰摇 | 镜头从低向高转动拍摄 |
| 向下俯摇 | 镜头从高向低转动拍摄 |
| 滚转倾斜 | 镜头沿轴向滚动 |

---

## 变焦类

| 运镜词 | 说明 |
|--------|------|
| 缓缓推近镜头 | 通过变焦拉近主体，逐渐改变构图 |
| 缓缓拉远镜头 | 通过变焦拉远主体，逐渐改变构图 |

> 注意：与"向前推进"不同，变焦是通过改变焦距实现，不改变机位。

## 运镜使用规则

### 英文保留规则

以下为专有名词，可保留英文：
- **FPV** - 第一人称视角无人机
- **POV** - 主观视角镜头

其他所有运镜描述必须使用中文，禁止使用英文。

### 运镜速度修饰

可配合速度修饰语使用：
- 缓慢/快速/匀速/加速/减速
- 示例：缓慢推近镜头、快速甩镜、加速环绕

### 运镜组合

一个切镜可包含多个运镜动作：
- 示例：向前推进同时缓慢向右环绕
- 示例：垂直上升俯视同时向后拉远

### 运镜与景别配合

| 运镜 | 适合景别 |
|------|----------|
| 固定镜头 | 任何景别，特写/近景居多 |
| 手持镜头 | 任何景别，强调真实感 |
| 向前推进 | 中景→近景→特写 |
| 向后拉远 | 特写→近景→全景 |
| 环绕类 | 中景→全景 |
| FPV穿越机 | 全景→中景（极速推进） |

## 运镜场景示例

### 紧张追逐

```
【切镜】全景，快速甩镜从追逐者切换到被追者。
【切镜】中景，FPV穿越机极速推进，跟随逃跑者穿过狭窄走廊。
```

### 情感对峙

```
【切镜】双人镜头，缓慢向右环绕，两人始终保持在画面两侧。
【切镜】近景胸像，缓缓推近镜头，聚焦于主角握紧的拳头。
```

### 战斗爆发

```
【切镜】大全景，固定镜头，展示双方阵容。
【切镜】中景，升格（慢动作），主角抽出武器，刀光划过。
【切镜】极近特写，手部特写，刀刃沾血。
```

### 内心独白

```
【切镜】近景胸像，固定镜头，角色背对镜头望向窗外。
【切镜】POV主观视角，透过窗户看到城市夜景。
【切镜】近景胸像，缓缓推近镜头，角色转身面向镜头，眼中含泪。
```
