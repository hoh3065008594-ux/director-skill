# 景别词库与角度规则

## 景别词库

| 景别 | 说明 |
|------|------|
| 极近特写 | 局部细节，如眼睛、嘴唇、手部 |
| 特写 | 面部占据画面大部分，可聚焦特定局部 |
| 近景胸像 | 胸部以上，保留少量环境 |
| 中景腰部 | 腰部以上，肢体语言丰富 |
| 中全景 | 膝盖以上，完整人物与环境互动 |
| 全景 | 人物全身，清晰展示姿态与位置关系 |
| 大全景 | 人物与环境同比例，环境为主 |
| 航拍俯瞰 | 俯视全局，展示空间关系与规模 |

---

## 特写局部规则

特写/极近特写必须补充局部说明，局部说明直接**替换**"特写"二字，禁止同时出现两者。

### 正确示例

- 眼部极近特写
- 手部特写
- 嘴唇特写
- 刀锋特写
- 泪滴特写

### 错误示例

- 特写，手部特写（重复）
- 极近特写，眼部极近特写（重复）
- 特写，手部（混用）

## 角度默认省略规则

### 正面与侧面

| 角度 | 默认行为 |
|------|----------|
| 正面 | 默认不写 |
| 斜前方45度 | 正常书写 |
| 正侧面90度 | 正常书写 |
| 斜后方 | 正常书写 |
| 正后方 | 正常书写 |
| 过肩镜头 | 正常书写 |

### 仰俯角度

| 角度 | 默认行为 |
|------|----------|
| 平视 | 默认不写 |
| 微微仰拍 | 正常书写 |
| 大角度仰拍 | 正常书写 |
| 贴地极度仰拍 | 正常书写 |
| 微微俯拍 | 正常书写 |
| 45度俯拍 | 正常书写 |
| 大角度俯拍 | 正常书写 |

### 组合角度

水平与垂直均非默认时，合并为一个词组不加逗号：

- 斜前方45度微微俯拍
- 正侧面大角度仰拍
- 斜后方贴地极度仰拍

### 非居中构图

居中 = 默认不写

非居中作为空间修饰语融入描述：
- 画面左侧三分法构图
- 前景遮挡留白右侧
- 右下角入画

## 朝向与表情规则

### 基本规则

- 正面朝镜头：动作前不标注朝向
- 背对镜头：动作前标注"背对镜头"
- 侧对镜头：动作前标注"侧对镜头"

### 表情限制

**关键规则**：背对/侧对镜头时，**禁止描述面部表情**

### 示例

正确：
- 侧对镜头，张三缓缓转身面向镜头，嘴角上扬。
- 背对镜头，李四站立不动，肩膀微微颤抖。

错误：
- 背对镜头，张三面露悲伤。（背对时无法看到表情）
- 侧对镜头，李四眼中含泪，微微一笑。（侧对时不应描述眼神/微笑）

## 构图修饰语

### 焦平面层次

- 浅景深虚化背景
- 深景深全部清晰
- 前景虚化
- 前后景虚化中间清晰

### 构图方式

- 三分法构图
- 对角线构图
- 框架构图
- 对称构图
- 黄金分割

### 特殊构图

- 前景遮挡
- 镜子/玻璃反射
- 倒影构图
- 延伸线引导

### 宽高比

- 16:9 宽银幕
- 2.39:1 电影宽银幕
- 4:3 经典画幅
- 1:1 方形画幅
- 9:16 竖屏
