## 一、视频核心：3+2 工作流 3.0

**定位**：不是提示词制造机（那是 2.0），而是与 Codex 全程共创的导演系统。

### 完整流程（视频演示"剧本分析→角色资产"）

| 步骤 | 内容 |
|---|---|
| ① 建账本 | 先不写提示词，建立**项目记账系统**（本地文件夹存档）——记录所有确认/待确认的资产、提示词、制作状态 |
| ② 剧本拆解 | 颗粒度拆解约 10 项：国家/年代、精准季节时间、人物小传、场景、贯穿道具等。**核心观点：资产制作占全流程 ≥50%** |
| ③ 情绪曲线图 | 自动生成 0-10 情绪曲线（0=平静，10=窒息）——标出铺垫/推进/高潮；**解决"音乐怎么加"**（哪些节点该有音乐一目了然）；双重用途：给创作者看 + 给模型做上下文准备 |
| ④ 视觉锁定 | AI 导演锁定整片视觉风格：经典影视作参考（演示：烈日凶风、谷和小屋）、拍摄器材、光线影调、色彩搭配、BGM 方案 |
| ⑤ 人物资产 | **血缘继承**：女儿与父母有血缘 → 先定父母长相再生成女儿；狼人基于男主形象推演。每次继承内部做一次**垫图(img2img)** → 一致性好的原因；可对话式修改；确认后出**三视图** |
| ⑥ 道具资产 | 只留**重复出现**的道具，单次出现的自动排除；资产+提示词存本地账本 |

**金句**："一个优秀的影片，都是一点一点抠出来的，盲目追求效率，质量一定不高。"

### 关键机制
- **情绪曲线双用途**：① 判断剧本结构（铺垫/推进/高潮是否合理）② 指导 BGM 节点
- **一致性 = 每次继承做一次垫图流程**
- **账本可见**：所有版本记录在内，无需手动下载

## 二、五个开源参考材料摘要

### 1. tvc-ai-director（TVC 广告导演 Skill Suite，guangjun5952）
- 10 子 skill：brief 诊断 → 创意提报 → 导演阐述 → PPM → 分镜 → AI prompt → 制作统筹 → 剪辑 → 客户审片解析 → 多模型路由
- 统一交接字段：`项目背景 / 当前阶段 / 已知信息 / 关键假设 / 待补信息 / 本阶段产物 / 下游注意事项 / 建议下一步`
- 图片 prompt 八层结构；视频 Seedance 式；分镜 prompt 合并表可导出 xlsx

### 2. ai-director-skill（tuoxie0102，AI 短片导演层）
- 流程：故事功能分析 → 分镜连续性引擎 → 风格翻译 → Character/World/Style 三锁 → 标准镜头卡 → Prompt 生成 → QA
- 输出《AI短片 Prompt 包》（含三锁、镜头卡、中英文图片/视频 prompt、QA 报告）

### 3. minimax-h3-broll-generator（guangjun5952，H3 口播 B-roll）
- T01–T21 共 21 种包装模板（结论金句/概念隐喻/数字冲击/证据摘录/流程/反馈/章节/全屏/3D 空间/关键词/交集/组织/对话/对比/证据链路/人物档案/3D 组装/地图/演进/能力树/机制）
- 提示词三版本：v1 ≤12字符（准确优先）/ v2 ≤28字符（表现力）/ v3 ≤18字符（平衡推荐）
- 安全门禁：明确批准 + 状态 approved + `--approved` + 素材齐备才生成
- **H3 强制无 BGM，只允许同期拟音环境音**（与本机 director 的"声音只用 H3 提示词生成"一致）

### 4. 超哥分镜导演 SD2.0（Coze，完整 SKILL.md 已抓取）
- 画风确认（8 预设 STYLE_TOKEN 三层）→ 分镜表（9 列，时长/批次规则）→ Seedance 2.0 批次提示词
- 自定义风格八步推导法；导演法则（视线/威胁切镜/动作拆解/台词特写）；运镜词库
